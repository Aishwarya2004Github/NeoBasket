# NeoBasket AI Engine integration

- AI API: http://localhost:8002
- Existing NeoBasket customer frontend: http://localhost:5173
- Existing NeoBasket backend: http://localhost:8080
- AI Engine reuses the existing PostgreSQL schema and never replaces the main cart/checkout backend.

Customer: Copilot, Cheapest Basket, Recommendations, Smart Refill, Recipes, Healthy Basket, Substitution, Forgot Something, Fridge Vision, ETA, Live Rider.
Admin: Command Center, Inventory Intelligence, Dynamic Pricing, Demand Forecast, Expiry Intelligence.
